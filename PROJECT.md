# US RPS & CES Program Database

## Overview

A queryable database of US Renewable Portfolio Standard (RPS) and Clean Energy Standard (CES) programs, covering:
- All programs that accrue REC/EAC obligations for serving load
- State-run procurements of renewable and zero-carbon energy (including storage)
- Historical compliance data and forward-looking targets through 2050

## Data Sources

**Authority policy:** The LBNL files below were a quick starting point to seed the database.
They are **not authoritative** — they contain errors and omissions (e.g. CT Class III is
absent). Do **not** validate or sanity-check reviewed states against LBNL. Primary sources
(state PUC/PURA sites, statutes, DSIRE) are the authority; verified values in
`programs/STATE.yaml` supersede LBNL. Do not modify the source Excel files.

| File | Contents |
|------|----------|
| `Historical RPS & CES Capacity Additions_August 2025.xlsx` | Regional capacity additions (MW-AC) by technology, off-taker, and RPS-relatedness, pre-2000 through 2024 |
| `Historical RPS & CES Target Achievement and Compliance Costs_August 2025.xlsx` | State-level RPS target achievement (%) and compliance costs (% of avg retail bill), 2000–2024 |
| `RPS & CES Targets and Demand_August 2025.xlsx` | Statewide sales, RPS-applicable sales, RPS/CES targets (%), and RPS demand obligation (GWh), 1998–2050 |

## Database Files

Generated by `python scripts/run_pipeline.py` into the `data/` directory.

| Parquet File | Source Sheet | Key Columns | Row Count |
|---|---|---|---|
| `capacity_additions.parquet` | Capacity Additions | region, technology, off_taker, rps_related, year, mw_ac | ~12,000 |
| `target_achievement.parquet` | Target Achievement | state, tier, year, achievement_pct | ~2,000 |
| `compliance_costs.parquet` | Compliance Costs | state, tier, year, cost_pct_retail_bill | ~1,500 |
| `statewide_sales.parquet` | Statewide Sales | state, year, gwh, is_projection | ~2,200 |
| `rps_applicable_sales.parquet` | RPS-Applicable Sales | state, year, gwh, is_projection | ~2,000 |
| `rps_targets_pct.parquet` | RPS & CES Targets (%) | state, program_notes, tier, year, target_pct, is_projection | ~7,000 |
| `rps_demand_gwh.parquet` | RPS & CES Demand (GWh) | state, program_notes, tier, year, gwh, is_projection | ~5,000 |

## State Summary Files

Per-state markdown summaries are written to `states/{STATE}.md` for each RPS/CES state. Each file includes:
- Program targets (historical + projected through 2050)
- RPS demand obligation (GWh)
- Historical target achievement rate
- Compliance costs
- Retail and RPS-applicable sales

### Query the database
```python
import pandas as pd

# CA 2030 RPS target
targets = pd.read_parquet('data/rps_targets_pct.parquet')
print(targets[(targets.state == 'CA') & (targets.year == 2030)])

# All states with RPS demand > 50,000 GWh in 2024
demand = pd.read_parquet('data/rps_demand_gwh.parquet')
print(demand[(demand.year == 2024) & (demand.gwh > 50000)].sort_values('gwh', ascending=False))

# Historical achievement for CO
ach = pd.read_parquet('data/target_achievement.parquet')
print(ach[ach.state == 'CO'].pivot(index='tier', columns='year', values='achievement_pct'))
```

## Data Conventions

- **Percentage values** are stored as decimals: `0.60` = 60% (not `60.0`)
- **Sentinel values** (`-`, `no data`) in source → `NaN` in output
- **`is_projection`** flag: `True` for years > 2025 (data vintage is August 2025)
- **State column** is always forward-filled (source uses Excel merged cells)
- **Tier names** have leading/trailing whitespace stripped; sub-tiers are identified by position in the data, not indentation
- **Capacity data** is regional (not state-level); see `region` column
